# MDNGHT Scents website

A lightweight, responsive two-page brand website for MDNGHT Scents. Home includes the hero/landing section and seven-fragrance collection. About Us contains the brand story. Every Order Now link opens Facebook Messenger.

## Before publishing

1. Open `main.js`.
2. Replace `YOUR_FACEBOOK_PAGE_USERNAME` with the public username of your Facebook Page. Example: `mdnght.scents` for `facebook.com/mdnght.scents`.
3. The fragrance prices and product images are intentionally not invented. Add real product photography and confirmed prices when ready.

## Run locally

- Install Node.js.
- Run `npm install`
- Run `npm run dev`

## Deploy to Cloudflare Pages

Connect the GitHub repository to Cloudflare Pages. Framework preset: Vite. Build command: `npm run build`. Build output directory: `dist`.
